# 战斗音效 1.1.0

独立的本机击杀、爆头、连杀与死亡音效模组，包含播放器、音频资源和可编译播放器源码。

## 试听与导入

打开模组设置的“模组操作”，直接选择音效包、类型和试听音量即可试听。
**不需要启用模组，不需要初始化运行环境，也不需要启动过服务端。**
自定义 WAV / MP3 导入同样可直接使用。试听使用当前窗口选项，不会自动开启模组或保存参数。
导入的音频保留在启动器自己的模组状态目录；在参数设置中选择对应音效包并保存，供对局播放。

## 对局播放

启用模组后，服务端运行时按玩家 ID 读取击杀/死亡事件并播放音效。
参数、开关和所选版本分别管理。未启用时只允许本地操作，不会监听对局事件。
本地导入与对局运行使用同一音频素材库，运行中的音效实例会读取新导入的音频。

## 运行方式

- entry.mjs：对局事件与常驻音效运行实例，跟随服务端。
- tools.mjs：单次本地试听/导入入口，无服务端依赖。
- audio-library.mjs：素材准备、试听及导入逻辑，共享已有自定义音频。
- resources/native/BF4KillSound.exe：现有播放器，保持原二进制。

本次为 1.1.0 的行为修正，模组参数与个人音频继续保留。source 目录含播放器源码，普通运行不需要 .NET SDK。
