# 组件来源

运行接口兼容 BF4 启动器外部模组 API v1（0.2.2）。

- 场景读取、绘制、音效协议来自本机 BF4-MOD-Easy 0.8.3 与 BF4-Host-Panel 0.8.3 组件。
- 枪械参数计划和绑定行为按实际 BF4PlayerEffects.exe（SHA256 a45e45a1e32ffab002223e0a5c17dda27ba9f01b3b842ca42d973ee748806e16）核对后恢复为可编译源，并重写独立生命周期、恢复与回读控制；不以旧的随包 PlayerEffects.cs 代替。
- 进程身份检查、阶段诊断、状态文件重试及程序入口为本次重写部分。
- 原组件、音效素材和第三方图形库的来源与授权信息随包保留。
