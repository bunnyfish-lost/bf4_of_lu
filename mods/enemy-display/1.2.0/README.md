# 敌人位置显示 1.2.0 · v2（1107）

针对 BF4 离线服务端 v2（1107）的独立模组。旧辅助程序仅识别 v1 客户端，升级后会停在“此组件未适配当前游戏文件”，本版更新了实际执行程序的版本识别，不仅修改说明文件。

在游戏画面上绘制敌方步兵方框和指示线，0 表示不限距离；保留只显示人机、前台显示、置顶和鼠标穿透。

关闭游戏后，在模组列表停用本功能旧版，再启用 1.2.0；旧版文件不删除。模组设置仍位于各自的配置窗口，不需要另外启动一个工具。

完整构建源位于 source。普通运行不需要 .NET SDK。运行记录位于启动器 data/mod-state 的对应状态目录。
