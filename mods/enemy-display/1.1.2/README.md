# 敌人位置显示 1.1.2

独立客户端模组，包含程序、绘制依赖和完整构建源。

## 本次修正

1. 给标记窗补齐分层窗与透明窗的组合，初始化为全局不透明度 255；绘制仍使用原来的逐像素透明合成。
2. 每次创建窗口句柄均重新初始化鼠标穿透；窗口不参与焦点选择，不捕获鼠标。
3. 保留 1.1.1 的持续置顶和窗口重建后的绘制资源恢复。
4. 日志增加 overlayInputTransparent，便于检查运行中的显示窗样式。

参数：方框、指示线、显示距离、只显示人机。距离 0 为不限距离。只标记屏幕内有效的敌方步兵，不启动自动瞄准。切回启动器时暂停显示。

在模组页刷新目录，关闭旧版敌人位置显示，启用 1.1.2 即可；无需重启游戏或服务器。各版本单独保存参数；同组实际运行列表最后启用的版本。

诊断位于启动器 data/mod-state 下 diagnostics/native.jsonl。读取、提交状态与用户实际可见的画面分别验证。外部标记窗以窗口化／无边框显示为目标。

## 构建

Windows PowerShell 5.1 或 PowerShell 7 执行 build.ps1；需要已安装 .NET SDK。构建会执行 GPU 像素自检，普通运行不需要 SDK。source 为全部构建源。
