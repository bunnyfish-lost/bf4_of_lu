# 自动瞄准 1.2.0 · v2（1107）

独立模组，适配 BF4 离线服务端 v2（1107）。本版更新实际辅助程序、加载脚本和运行回执，不仅修改兼容性说明。

使用：正常退出客户端后，在模组列表停用本功能旧版，再启用 1.2.0；设置仍在本模组配置窗口。新旧版本并存，启动器不自动切换或改排序。

运行回执绑定当前模组会话、辅助程序 PID、客户端 PID 和服务端 PID。等待角色部署和出错不会直接算作实际效果已验证。

支持身体/头部、所选鼠标触发键、范围和过渡速度；F8 暂停/恢复，F9 切换部位。只在本机游戏前台发送鼠标输入。

构建：运行包根目录 build.ps1，需 .NET SDK。C# 源码在 source；普通玩家运行不需要 SDK。原生 DLL 此版未改字节，其源码一并保留。

对局验证：执行器版本识别、静态补丁位置与隔离服务端加载已检查。真人入局后的最终效果仍需验证。
